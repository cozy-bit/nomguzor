# Nomguzor (Номгузор)

> Современный интерактивный веб-сервис и реестр национальных таджикских имён. Помогает родителям осознанно выбирать благозвучные и традиционные имена с подробным толкованием значений, этимологией и статусом официального государственного реестра.

🔗 **Демо:** [nomguzor.vercel.app](https://nomguzor.vercel.app/)

---

### 🛠 Стек технологий

- **Фреймворк:** Next.js (App Router, React, TypeScript)
- **Стилизация:** Tailwind CSS v4
- **Управление состоянием:** Zustand (с синхронизацией в LocalStorage)
- **Поиск:** Fuse.js (нечёткий fuzzy-поиск с учётом специфики алфавита)
- **Иконки:** Lucide React

---

### 🚀 Быстрый старт

1. **Клонирование репозитория и установка зависимостей:**
```bash
git clone https://github.com/cozy-bit/nomguzor.git
cd nomguzor
npm install
```

2. **Запуск в режиме разработки:**
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

3. **Сборка для продакшена:**
```bash
npm run build
npm run start
```
